# Библиотека медиа

## footage/ — футажи

- **Свои съёмки:** лучший вариант, это живой город. Снимайте вертикально (9:16), 5–15 секунд,
  без людей крупным планом. Загружайте сюда через GitHub (Add file → Upload files).
- **Сток:** workflow «Fetch footage» скачивает вертикальные ролики с Pexels по запросу.
  Рядом с каждым роликом лежит `.json` с автором и ссылкой на источник.

## music/ — музыка

Instagram не даёт добавить трек из своей библиотеки через API, поэтому музыка вшивается в видео.
Популярные треки из чартов вшивать нельзя: Instagram заглушит звук или удалит ролик.
Берём треки со свободной лицензией, но в трендовых стилях:

| Где брать | Лицензия |
|---|---|
| [Pixabay Music](https://pixabay.com/music/) | бесплатно, можно в соцсетях, без указания автора |
| [YouTube Audio Library](https://studio.youtube.com/) → Аудиотека | бесплатно, у части треков нужно указать автора |
| Meta Sound Collection (Meta Business Suite → Ресурсы) | бесплатно для Instagram и Facebook |

**Правило:** если в ролике много текста, то трек без слов. Слова в песне мешают читать.

Называйте файлы по настроению, тогда их легко подбирать:

| Префикс | Когда |
|---|---|
| `calm-` | спокойные подборки, справочник, полезное |
| `upbeat-` | события, выходные, фестивали |
| `night-` | вечер, концерты, клубы |
| `epic-` | большие события (турнир, Карнавал, Rheinkirmes) |
| `vocal-` | с вокалом, для роликов почти без текста |

Пример: `upbeat-house-01.mp3`.

Если нужен по-настоящему трендовый звук из Instagram, я готовлю ролик без музыки,
а вы добавляете трек в приложении и ставите публикацию по расписанию. Это займёт пару минут.
