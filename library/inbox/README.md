# Сюда загружать свои фото и видео

Add file → Upload files → перетащить файлы → Commit.

GitHub сам обработает их за пару минут и переложит:
- видео → `library/footage/own-*.mp4`: **оригинальный звук удаляется**, сжатие, H.264;
- фото → `library/photos/own-*.jpg`: уменьшение до 2160 px, **метаданные и GPS удаляются**.

Ограничение загрузки через сайт GitHub — 25 МБ на файл. Длинные ролики лучше обрезать до 10–20 секунд
(в телефоне: «Изменить» → обрезать) — для Reels нужны короткие куски.

Подсказка к названиям: `rhein-sunset.mp4`, `altstadt-night.jpg`, `koe-christmas.mp4` — по названию я подбираю кадры к теме.
