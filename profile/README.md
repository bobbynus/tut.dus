# Оформление профиля @tut.dus

Всё, что нужно заполнить в Instagram. Тексты копировать как есть.

## 1. Тип аккаунта

**Настройки → Тип аккаунта и инструменты → Перейти на профессиональный аккаунт → Автор.**
Именно «Автор», а не «Бизнес»: у бизнес-аккаунтов урезанная музыкальная библиотека (только Meta Sound Collection,
без популярных треков). Категория, кнопки связи, ответы в директе и автопостинг через API у «Автора» тоже есть.

**Музыка к постам добавляется только в мобильном приложении.** С компьютера (instagram.com, Meta Business Suite)
и через API музыку к фото и каруселям не добавить. Чтобы выложить пост с музыкой заранее, его можно запланировать
прямо в приложении: при публикации «Дополнительные настройки» → «Запланировать».

- **Категория:** «Новостная и медиакомпания» (News & Media Website). Если такой нет: «СМИ/новости».
- **Показывать категорию в профиле:** да.

| Имя пользователя | `tut.dus` | |

> Поле «Имя» участвует в поиске Instagram, поэтому в нём слова «Дюссельдорф» и «афиша».

**Описание (bio), 132 из 150 символов:**

```
Дюссельдорф на русском 📍
Что сегодня, куда пойти, к кому обратиться
🩺 Справочник врачей — скоро

```

Когда справочник заработает, третью строку заменить на: `🩺 Напиши «врач» в директ — пришлём список`

## 3. Контакты

**Редактировать профиль → Параметры связи:**
- Эл. почта: _добавить, когда будет ящик для сотрудничества_
- Телефон: не указывать
- Адрес: не указывать (физического офиса нет)
- Кнопка действия: не нужна

## 4. «Актуальное» (Highlights)

Обложки в `highlights/`. Порядок и названия (до 15 символов):

| Обложка | Название | Что туда складывать |
|---|---|---|
| `hl-about.png` | О нас | Знакомство, правила, как прислать событие |
| `hl-events.png` | Афиша | Главные события месяца |
| `hl-free.png` | Бесплатно | Бесплатные события и места |
| `hl-kids.png` | С детьми | Детские события, площадки, музеи |
| `hl-doctors.png` | Врачи | Подборки специалистов (когда появятся) |
| `hl-important.png` | Важное | Забастовки, перекрытия, праздники, правила |
| `hl-contact.png` | Связь | Сотрудничество, реклама, как связаться |

Чтобы создать «Актуальное», нужна хотя бы одна сторис. Первые сторис можно сделать из слайдов вводного поста.
Обложка: «Редактировать актуальное» → «Изменить обложку» → выбрать картинку из галереи.

## 5. Сообщения

**Настройки → Инструменты для бизнеса → Часто задаваемые вопросы** (до 4, показываются при первом сообщении):

1. Что интересного сегодня в Дюссельдорфе?
2. Хочу рассказать о событии
3. Сотрудничество и реклама
4. Ищу русскоязычного врача

**Быстрые ответы** (Настройки → Инструменты для бизнеса → Быстрые ответы). В директе набираешь ярлык и получаешь готовый текст:

| Ярлык | Текст |
|---|---|
| `/событие` | Спасибо! Пришлите, пожалуйста, название, дату, время, адрес, цену и ссылку. Мы проверим и, если подойдёт, расскажем в ближайшей подборке. |
| `/реклама` | Здравствуйте! Спасибо за интерес к ТУТ.DUS. Расскажите коротко о компании и о том, что хотите разместить, и мы пришлём варианты и условия. Реклама у нас всегда с пометкой «реклама». |
| `/врач` | Справочник русскоязычных врачей сейчас в работе. Подпишитесь, чтобы не пропустить запуск. А пока ищите в официальном поиске KV Nordrhein (patienten.kvno.de): там есть фильтр по языку. |
| `/сегодня` | Все события на сегодня в наших сторис. Если ищете что-то конкретное (с детьми, бесплатно, концерт), напишите, подскажем. |
